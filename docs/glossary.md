# 용어집

이 저장소 문서에 나오는 용어를 처음 보는 사람을 위한 설명. 로봇 분야 지식이 없어도 읽을 수 있게 썼다.

## 하드웨어

| 용어 | 뜻 |
|---|---|
| 로버 | 바퀴로 움직이는 이동 로봇. 여기서는 **UEL Rover** |
| 차동구동 | 좌우 바퀴의 속도 차이로 직진·회전하는 방식. 두 바퀴가 같은 속도면 직진, 다르면 회전 |
| 로버 컴퓨터 (Jetson) | 로버에 실려 있는 컴퓨터(NVIDIA Jetson). ROS 2 프로그램이 여기서 돈다 |
| 제어보드 (OpenRB-150) | 모터를 직접 구동하고 조종기 신호를 읽는 작은 보드. 안전 정지도 여기서 처리한다 |
| 다이나믹셀 | 제어보드에 연결된 모터(서보) 종류. 이 로버는 ID 1 이 좌, ID 2 가 우 바퀴 |
| 조종기 (RC) | 사람이 손으로 쥐는 무선 조종기. 수신기가 로버에 달려 있고, 스위치 위치가 PWM 신호(µs 단위 펄스 폭)로 제어보드에 들어간다 |
| GCS (지상국) | Ground Control Station. 로버 밖의 PC 에서 로버 상태를 보고 조종하는 쪽 |

## 소프트웨어

| 용어 | 뜻 |
|---|---|
| ROS 2 (Jazzy) | 로봇 소프트웨어를 만들 때 쓰는 공개 프레임워크. Jazzy 는 버전 이름이다 |
| 노드 | ROS 2 에서 돌아가는 프로그램 하나. 이 저장소의 `commander`, `monitor`, `gcs_teleop` 이 노드다 |
| 토픽 | 노드끼리 메시지를 주고받는 이름 붙은 통로 (예: `/cmd_vel`). 보내는 쪽을 **발행**, 받는 쪽을 **구독**이라 한다 |
| launch | 여러 노드를 한 번에 실행하는 스크립트 (`*.launch.py`) |
| colcon | ROS 2 워크스페이스를 빌드하는 도구 |
| micro-ROS, `micro_ros_agent` | 작은 보드가 ROS 2 에 참여하게 해 주는 기술. 제어보드는 USB 시리얼로 로버 컴퓨터의 agent 와 통신하고, agent 가 이를 ROS 2 토픽으로 바꿔 준다 |
| Foxglove, `foxglove_bridge` | Foxglove 는 로봇 데이터를 보고 조종하는 앱. `foxglove_bridge` 는 로버의 토픽을 WebSocket 으로 GCS 에 내보내는 노드 |
| `/cmd_vel`, Twist | 로버에게 "직진 속도 `linear.x` (m/s), 회전 속도 `angular.z` (rad/s)" 를 알리는 속도 명령 |
| `/diagnostics` | 장치 상태를 OK / WARN / ERROR / STALE 로 알리는 표준 토픽 |

## 이 프로젝트의 개념

| 용어 | 뜻 |
|---|---|
| 드라이브 모드 | 조종기 CH7 스위치로 고르는 **STOP / AUTO / RC** 세 가지 상태. 누가 로버를 움직일지 정한다. [사용법](usage.md#조종기-스위치-드라이브-모드) |
| STOP | 즉시 정지. 처음 켤 때 두는 위치 |
| AUTO | 소프트웨어(`/cmd_vel`, GCS)가 내린 명령으로 움직이는 모드 |
| RC | 조종기로 직접 운전하는 모드. 소프트웨어 명령은 무시된다 |
| 워치독 | 일정 시간(여기서는 500 ms) 새 명령이 없으면 자동으로 멈추는 안전장치 |
| 클램프 | 값이 상한을 넘으면 상한으로 잘라 내는 것. commander 가 속도에 적용한다 |
| 데드맨 스위치 | 사람이 조작을 멈추면(스위치를 놓으면) 동작도 멈추는 안전 스위치 |

## 단위

| 단위 | 뜻 |
|---|---|
| m/s | 초당 미터. 직진 속도 |
| rad/s | 초당 라디안. 회전 속도 |
| rpm | 분당 회전수. 바퀴 회전 속도 |
| ms, µs | 밀리초(1/1000 초), 마이크로초(1/1,000,000 초) |

## 선택 기능(examples)에 나오는 용어

기본 구성에는 들어 있지 않고 [examples](../ros2_ws/src/uel_rover/examples/README.md) 에서 쓰인다.

| 용어 | 뜻 |
|---|---|
| 오도메트리 (`/odom`) | 바퀴 회전량으로 로버가 얼마나 움직였는지 추정한 값 |
| URDF | 로봇의 형태와 부품 위치를 적은 파일 |
| TF | 좌표계 사이의 위치 관계. 예: `odom → base_link → camera_link` |
| Nav2 | ROS 2 자율주행(경로 계획·주행) 패키지 모음 |
| SLAM, AMCL | SLAM 은 지도를 만들면서 위치를 추정하는 기술, AMCL 은 이미 있는 지도에서 위치를 추정하는 기술 |
